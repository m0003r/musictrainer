# Music Trainer

Веб-тренажёр для формирования устойчивых связей между четырьмя представлениями ноты:

1. нотная запись в разных ключах;
2. название ноты в разных языковых системах;
3. положение на фортепианной клавиатуре;
4. звучание.

Первый срез — упражнения с выбором ответа: гибкие уровни, все семь ключей, ключевые и случайные знаки, экранная и физическая MIDI-клавиатура, а также воспроизведение через Web Audio или MIDI OUT. Продуктивная запись нот и ритм зафиксированы как следующие этапы.

Подробности: [продуктовый контракт](docs/product-contract.md), [дизайн](docs/design.md), [связь с упражнениями Хвостенко](docs/khvostenko-evidence.md), [лестница сложности](docs/difficulty-ladder.md), [продуктивная запись](docs/productive-note-entry.md), [накопленные вопросы](docs/open-questions.md).

## Запуск

Требуется Node.js 20.19 или новее.

1. `npm install`
2. В одном терминале: `npm run dev:api`
3. В другом терминале: `npm run dev:web`
4. Открыть `http://localhost:5173`

SQLite-база создаётся локально в `data/music-trainer.sqlite` и не попадает в git. Проверки: `npm run test` и `npm run build`.

При первом открытии достаточно создать профиль по имени, как игровой слот сохранения. Email и пароль не нужны; любой локальный профиль можно выбрать с этого компьютера. Текущая dev-схема намеренно не поддерживает перенос старых тестовых аккаунтов: после изменения формата база может быть пересоздана.
