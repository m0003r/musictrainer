# Накопленные вопросы

Ответы перенесены в продуктовый контракт и DESIGN. Открыты только решения, которые действительно отложены.

- Какой интервал отсроченной проверки и какие пороги точности/покрытия считать устойчивым освоением?
- Как именно тональный контекст и пользователь должны выбирать между допустимыми энгармоническими написаниями в будущем продуктивном вводе?
- Каким должен быть отдельный контракт ритмического тренажёра после стабилизации звуковысотного ядра?

Интерфейс продуктивной записи больше не открыт как общий вопрос: целевое решение — клик/тап по дискретной позиции нотоносца, клавиатурное управление и MIDI/виртуальная клавиатура как равноправные способы; drag может быть только дополнительным ускорителем. Детали и ещё не утверждённые части описаны в [productive-note-entry.md](productive-note-entry.md).
